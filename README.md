# ⚽ 热血绿茵 · 3D 实时足球

基于 **Three.js** 的网页 3D 足球游戏，4v4 实时对战电脑，所有模型、纹理、音效全部程序化生成，零外部素材。

## 运行

```bash
npm install
npm run dev        # 打开 http://localhost:5173
```

打包发布：`npm run build`（产物在 `dist/`）。

## 玩法

| 按键 | 操作 |
|------|------|
| W A S D / 方向键 | 移动 |
| Shift | 冲刺（消耗体力） |
| 空格（按住蓄力） | 射门，力度越大球速越快 |
| E 或 J | 传球（自动选择最佳队友，传完自动切人） |
| Q | 手动切换到离球最近的队友 |
| Esc / P | 暂停 |

- **难度**：简单 / 普通 / 困难 / 传奇 — 影响电脑的速度、反应、抢断凶狠度、射门精度和门将扑救能力（困难以上会双人逼抢）。
- **规则**：常规时间打平进入 **金球大战**，先进球者胜；球不出界（边界弹墙，节奏不断）。
- **娱乐性**：蓄力射门、世界波横幅、进球慢动作 + 彩带 + 观众跳跃欢呼、程序合成的踢球声/哨声/人群声、小地图、体力条、门柱金属声。

## 代码结构

```
src/
├── main.js      # 渲染器、输入、菜单交互、主循环
├── stadium.js   # 球场建模：草坪画线、球门球网、看台+2600观众、灯塔、广告牌、天空
├── entities.js  # 足球（物理/轨迹/碰撞）与球员（程序化人物模型+跑动动画）
├── ai.js        # 难度参数、球队AI（追球/逼抢/跑位/带球决策/门将预判）
├── match.js     # 比赛状态机、控球与抢断、射门传球、进球判定、HUD、小地图
├── audio.js     # WebAudio 程序化音效合成
└── fx.js        # 进球彩带粒子
```

调试：控制台可用 `window.__game`（含 `match`、`world`、手动步进 `step(dt)`）。
