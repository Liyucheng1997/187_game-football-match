# 热血绿茵 · Blazing Pitch —— 游戏设计文档

## 1. 定位

**街机风 5v5 3D 足球**。参考对象与各自借鉴点：

| 参考 | 借鉴 |
|------|------|
| FIFA Street / FIFA Volta | 5 人制节奏、笼式场地、花式过人 |
| 马里奥前锋（Mario Strikers） | 热血槽 → 必杀射门，门将被"烧穿"的爽快感 |
| Sensible Soccer / Super Sidekicks | 上手 10 秒、一键传射、比赛 4 分钟一局 |
| FIFA / 实况足球 | 蓄力射门 + 完美时机窗口、一脚出球、直塞/传中、定位球、黄红牌、回放 |
| Rocket League | 本地同屏多人、手柄优先、短局高频的"再来一局" |

核心体验：**每 20~30 秒就有一次射门机会，每 1~2 分钟就有一个值得回放的进球**。

## 2. 核心玩法

### 2.1 操作（键盘 / 手柄）

| 动作 | 键盘 1 | 手柄 | 说明 |
|------|--------|------|------|
| 移动 | WASD | 左摇杆 | 相对屏幕方向；点球视角自动转换 |
| 冲刺 | Shift | RT | 消耗体力；带球冲刺会把球趟远（易被断） |
| 短传 / 抢断 | J | A | 有球：按方向选队友；无球：近身抢断 |
| 射门 / 铲球 | K（按住蓄力） | B | 在绿色区间松开 = 完美射门；无球：铲球 |
| 直塞 | L | Y | 打队友身前空当 |
| 高球 / 传中 | I | X | 边路自动变为传中，禁区队友可头球 |
| 换人 | Q | LB | 按方向优先挑人 |
| 花式过人 | 空格 | RB | 马赛回旋 / 变向突破，降低被抢断概率 |
| 必杀射门 | E | RB+B | 热血槽满后可用 |
| 弧线射门 | 按住 U | LT | 射门带侧旋，绕过人墙 |

**预输入**：传球/射门键可以在来球之前按下，球到脚下时自动一脚出球（凌空、头球同理）。

### 2.2 物理

- 足球：重力 + 二次空气阻力 + **马格努斯力**（弧线球、上旋下坠）+ 地面滚动摩擦 + 弹跳。
- 天气影响：雨天球更滑、滚得更远；雪天球更慢、弹跳更低，并自动换橙色雪地球。
- 门柱/横梁圆柱碰撞（带"哐"的金属声和火花），球网可形变、会被打鼓。
- 射门/传球使用**弹道求解器**：给定目标点、速度与旋转，迭代求出初速度，保证弧线球也能精准落到瞄准点，误差完全由球员能力、力度、压迫程度决定。

### 2.3 攻防系统

- **控球**：球贴在脚前，速度越快球越远；冲刺时周期性"趟球"，给对手抢断窗口。
- **停球**：来球越快越难停，传控能力决定第一脚触球质量。
- **抢断**：站立抢断（成功率由防守 vs 盘带决定，对方花式过人时大幅下降）；铲球（先碰球合法，先碰人犯规，从背后铲大概率黄牌，两黄变红）。
- **身体对抗**：高速冲撞持球人有几率挤掉球；射门会被挡出（封堵）。
- **门将**：读球 → 横移封角 → 在来球前约 0.4 秒起跳，扑救成功率与反应、距离、球速、高度、落点相关；可接住、可扑出，禁区内单刀会出击封堵，会抢高空球。

### 2.4 规则

- 标准规则：界外球（踢入）、角球、球门球、任意球（近距离自动排人墙）、禁区内犯规判点球、黄/红牌、上下半场换边、补时。
- 笼式足球：四面玻璃挡板，球永不出界，节奏更快。
- 杯赛淘汰赛平局直接进入**点球大战**（5 轮 + 突然死亡）。

### 2.5 热血槽 & 必杀射门

- 成功传球、抢断、扑救、花式过人、控球都会积累热血槽。
- 槽满后可以释放**热血必杀射门**：火焰拖尾、慢动作、镜头震动，门将扑救能力大幅下降，即使扑到也可能被"烧穿"。
- 双方 AI 同样会使用，逼玩家在对手槽满时加强防守。

## 3. AI

- **阵型**：菱形 1-1-2-1（门将 / 后卫 / 左右中场 / 前锋），随球的位置整体平移、收缩。
- **进攻**：持球人每隔反应时间评估"射门 / 各队友传球（地面、直塞、传中、高球）/ 盘带 / 花式过人 / 必杀"，基于 xG 模型、传球线路安全度、空位程度、推进价值打分，并加入与难度相关的噪声。无球队员搜索周边空位点，前锋在持球人面朝前方时前插反越位。
- **防守**：1~2 人逼抢（站在持球人与球门之间，伺机抢断/铲球），其余人按威胁盯人或回到防守位置。
- **截球**：所有球员基于足球轨迹预测计算最早拦截点。
- **难度**（新手/职业/明星/传奇）调节：反应时间、决策噪声、射门误差、逼抢人数、抢断凶狠度、门将水平、跑速、花式动作频率、鲁莽犯规概率。

## 4. 模式与成长（耐玩度）

| 模式 | 内容 |
|------|------|
| 快速比赛 | 13 支队伍任选（含自建俱乐部），难度、时长、白天/黄昏/夜场、晴/雨/雪、标准/笼式 |
| 本地多人 | 最多 2 键盘 + 4 手柄，任意组合 1v1、2v2、2vCPU 合作 |
| 冠军杯赛 | 新秀杯 → 精英杯 → 冠军杯 → 传奇杯，8 队淘汰赛，逐级解锁；决赛可能遇到隐藏强队「神龙」 |
| 点球大战 | 独立小游戏 |
| 我的俱乐部 | 自定义队名、缩写、球衣配色和图案；用金币训练 5 项属性（各 10 级）；购买比赛用球 |
| 成就 | 18 项（帽子戏法、世界波、必杀进球、零封、逆转、杯赛冠军……），桌面版同步到 Steam 成就 |

金币来源：每场比赛（按难度加成）、每个进球、杯赛晋级与夺冠奖金。

## 5. 表现层

- **球员**：13 关节程序化骨架，脸部（眼、眉、鼻、耳）、8 种发型、6 种肤色、多色球鞋；球衣纹理实时生成（6 种图案 + 背号 + 背后名字 + 胸前号码/队徽），门将手套与专用球衣。
- **动画**：程序化跑动（膝盖弯曲、摆臂、躯干扭转、转弯侧倾）、踢球（引腿 → 击球 → 随摆）、传球脚内侧、凌空、头球起跳、抢断、滑铲、倒地/起身、门将预备姿势/鱼跃/接球/抛球、花式回旋、5 种进球庆祝（滑跪、飞机、后空翻、跳舞、振臂）、失球沮丧。
- **球场**：程序化草坪（割草条纹、磨损、雪地）、完整画线、可形变球网、碗形双层看台（近侧开放给转播机位）、顶棚灯带、包厢发光带、4 座灯塔、大屏幕实时比分、滚动 LED 广告、替补席、角旗。
- **观众**：约 1 万名 GPU 实例化观众，按主客队配色分区，进球时对应看台欢呼跳跃、举手。
- **光照**：白天 / 黄昏 / 夜场 × 晴 / 雨 / 雪，ACES 色调映射 + 泛光（夜场灯光、必杀火焰）。
- **镜头**：转播 / 近景 / 高空三种比赛视角；点球背后视角；进球环绕特写；进球**即时回放**（两种机位，关键时刻慢放）；开场球员列队镜头。
- **音效（零素材，全部实时合成）**：踢球力度分级、停球、门柱金属声、球网、哨声（开球/犯规/半场/终场）、人群底噪 + 节奏助威鼓点、欢呼、惋惜、嘘声、必杀火焰音效、菜单背景音乐。
- **HUD**：转播风比分牌、双方热血槽、球员头顶标签（真人颜色、体力、蓄力条与完美区间）、雷达小地图、文字解说、定位球提示、黄红牌弹窗、成就提示。

## 6. 后续可扩展

- 在线对战（WebRTC / Steam Networking）。
- 更多场馆（街头笼、沙滩、雪山）与赛季联赛模式。
- 球员个人养成与转会。
- 多语言（英/日/韩）——UI 文本已集中在界面层，便于抽取。
